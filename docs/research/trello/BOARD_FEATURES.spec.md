# Trello Board Features — IA Spec (Kanban brand)

Source recon: public Trello board + known Trello product IA. Visuals map to Kanban teal/paper — not Trello blue.

## Board menu (right sheet)
- Change background (colors / gradients / photos)
- Labels (CRUD board labels)
- Archived items (cards + lists, restore)
- Power-Ups (enable/disable installed packs)
- Automation / Butler hub
- Settings (prefs: label text, cover size)
- Save as template / Close board

## Butler hub tabs
- Rules (event → multi-actions)
- Card buttons / Board buttons (click → multi-actions)
- Calendar commands (schedule → multi-actions)

## Views
- Board, Table, Calendar, Timeline (existing)
- Dashboard (aggregations tiles)
- Map (card lat/lng markers)

## Marketplace
- Power-Up packs + Sticker packs (+ existing template/automation)

## Stickers
- Pack install → board enable → place on card (x,y,rotate)
